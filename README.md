# Mindustry Multi-Sector Simulator

> **Автономная система честной параллельной фоновой симуляции секторов кампании для Mindustry v146+ с межсекторной маршрутизацией ракетных площадок (Launch Pads) и синхронизацией ресурсов ядер.**

---

## ⚡ Ключевые функции

* **Честная симуляция 60 TPS:** Каждый фоновый сектор запускается в изолированном headless-сервере Mindustry. В отличие от встроенного приближения игры, здесь честно работают фабрики, буры, конвейеры, логические процессоры и сторонние моды.
* **Аппаратное ускорение тиков (1x / 2x / 5x / 10x):** Разгон скорости любого фонового сектора без десинхронизации физики через `Time.setDeltaProvider`.
* **Живое отображение ресурсов ядра в F8:** Честный вывод количества предметов в реальном времени (как для фоновых секторов, так и для активного сектора игрока прямо из оперативной памяти).
* **Автоматическая приостановка и возобновление (Auto-Suspend / Resume):**
  * При переходе игрока на симулируемый сектор фоновый воркер сбрасывает данные на диск и приостанавливается, а накопленные ресурсы мгновенно инжектируются в ядро.
  * При выходе из сектора (в меню, на карту планет или другой сектор) симуляция автоматически возобновляется с сохраненными скоростью и целями.
* **Межсекторная маршрутизация Launch Pads:** Ракетные площадки пересылают добытые ресурсы напрямую в ядра целевых секторов в реальном времени.
* **Контроль целей по волнам (`/goal`):** Автоматическая остановка сектора при достижении целевой волны (например, для защиты сектора).
* **Zero External Dependencies:** Python-оркестратор написан на стандартной библиотеке (Python 3.10+ stdlib) и не требует сторонних pip-пакетов для работы.
* **Автозагрузка сервера:** Автоматическое скачивание `server-release.jar` при первом запуске, если файл отсутствует.

## 🚀 Быстрый старт на новом компьютере

### 1. Системные требования
* **Mindustry:** v146 или выше (Steam, itch.io или самостоятельный билд).
* **Java:** OpenJDK / Oracle JDK 17 или новее (для headless-воркеров).
* **Python:** 3.10 или новее.

### 2. Клонирование репозитория
```bash
git clone https://github.com/LightSix56/mindustry-multi-sector-sim.git
cd mindustry-multi-sector-sim
```

### 3. Установка клиентского мода
Скопируйте папку `mods/multi-sector-sim` в каталог модов Mindustry:
* **Windows:** `%APPDATA%\Mindustry\mods\multi-sector-sim`
* **Linux:** `~/.local/share/Mindustry/mods/multi-sector-sim`

*(Либо запакуйте папку `mods/multi-sector-sim` в `.zip` и импортируйте через меню игры: Моды -> Импорт мода).*

### 4. Запуск оркестратора
* **Windows:** Запустите `start_sim.bat` двойным кликом.
* **Linux / macOS / Терминал:**
  ```bash
  python run_orchestrator.py
  ```
Оркестратор запустит локальный REST API на `http://127.0.0.1:8765`.

## 🎮 Управление в игре

### Горячие клавиши
* **F8:** Открыть/закрыть окно управления фоновыми секторами (работает в любом месте: главное меню, карта кампании, пауза, игровой процесс).
* Кнопка **«Фон-Сектора»** также продублирована в главном меню, меню паузы и в правом верхнем углу игрового HUD.

### Элементы управления в окне F8
* **«Запустить» (зеленая кнопка):** Запуск симуляции выбранного сектора.
* **«1x / 2x / 5x / 10x» (желтая кнопка):** Смена множителя скорости тиков.
* **«🎯» (Цель):** Установка целевой волны для авто-остановки.
* **«💾» (Сохранить):** Немедленный сброс состояния воркера в файлы сохранений `%APPDATA%\Mindustry\saves`.
* **«✕» (Остановить):** Завершение симуляции сектора.
* **«★ ВЫ НА ЭТОМ СЕКТОРЕ»:** Индикатор активного сектора игрока с живыми ресурсами ядра.

### Чат-команды
* `/sim` — открыть окно симуляции секторов.
* `/boost <множитель> [сектор]` — задать скорость (например: `/boost 10` или `/boost 2 170`).
* `/goal <волна> [сектор]` — установить целевую волну (например: `/goal 50`).
